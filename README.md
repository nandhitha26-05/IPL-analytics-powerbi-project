🏏 IPL Analytics Dashboard — Power BI

📌 Project Overview

This project is an IPL Analytics Dashboard created using Microsoft Power BI.

The dashboard transforms IPL match data into interactive visualizations to analyze team performance, player performance, match results, and overall tournament statistics.

🎯 Objectives

- Analyze IPL team performance
- Analyze player performance
- Identify winning and losing patterns
- Analyze match results and statistics
- Create an interactive Power BI dashboard
- Present insights using data visualization

🛠️ Tools & Technologies

- Power BI
- Power Query
- DAX
- Data Cleaning
- Data Visualization

📊 Dashboard Features

The dashboard provides insights into:

- 🏆 Team performance
- 🏏 Player statistics
- 🎯 Match results
- 📈 Performance trends
- 🥇 Winning teams
- 📊 Key IPL statistics

🔄 Project Workflow

IPL Dataset
     ↓
Data Cleaning
     ↓
Power Query
     ↓
Data Modeling
     ↓
DAX Measures
     ↓
Interactive Dashboard
     ↓
